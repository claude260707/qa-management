# 쇼핑몰 유형 TC 설계 스킬

쇼핑몰(커머스) 유형 프로젝트에서 기획서만으로는 놓치기 쉬운 예외 케이스 체크리스트.
TC 생성 시 이 문서의 항목들을 기획서 내용과 함께 검토하여, 기획서에 명시되지 않았더라도
반드시 하나 이상의 TC로 다뤄야 한다.

## 1. 쿠폰 / 프로모션
- 동일 쿠폰 중복 적용 시도
- 중복 적용 불가 쿠폰 간 조합 시도
- 최소 주문 금액 미달 시 쿠폰 적용
- 쿠폰 유효기간 만료 직전/직후 경계값
- 쿠폰 적용 후 상품 취소 시 재계산
- 최대 적용 가능 쿠폰 수 초과

## 2. 재고
- 결제 실패/취소 시 차감된 재고 롤백
- 동시 주문 시 재고 경합 (동시성)
- 재고 0개 도달 시점의 주문 시도
- 재고 대량 요청(부하) 시 음수 방지
- 옵션(사이즈/색상)별 재고 독립 관리 여부

## 3. 결제
- PG사 응답 타임아웃
- PG사 콜백 유실/지연 시 주문 상태 정합성
- 복수 상품 중 일부만 결제 실패
- 결제 수단별(카드/간편결제/포인트) 예외 처리
- 결제 금액과 실제 청구 금액 불일치

## 4. 배송 / 주문 상태
- 부분 배송(분리 배송) 처리
- 주문 취소 가능 시점 경계값 (배송 시작 전/후)
- 반품/환불 정책과 실제 처리 로직 일치 여부

## 5. 권한 / 인증
- 비로그인 사용자의 결제 시도
- 타인 계정으로 주문 조회/취소 시도
- 세션 만료 중 결제 진행

## 6. 데이터 정합성
- 장바구니-재고-주문 데이터 간 동기화
- 새로고침/재진입 시 할인/쿠폰 상태 재검증
- 상품 가격 변경 시 이미 담긴 장바구니 반영 여부

## 7. 네트워크 / 외부 장애
- 외부 API(배송사, PG사) 장애 시 사용자 안내
- 재시도(retry) 로직 존재 여부 및 중복 처리 방지
