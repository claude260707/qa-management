# 내부 관리 시스템 유형 TC 설계 스킬

내부 관리/운영 시스템(어드민, 사내 도구, 백오피스 등) 프로젝트에서 기획서만으로는
놓치기 쉬운 예외 케이스 체크리스트.

## 1. 권한 / 인증
- 역할(관리자/일반 담당자 등)별 화면·기능 접근 제한
- 권한 없는 사용자의 URL 직접 접근(우회 접근) 시도
- 세션 만료 후 요청 시 처리
- 타 부서/타 프로젝트 데이터 접근 제한 (데이터 격리)

## 2. 데이터 정합성
- 동시에 같은 데이터를 여러 담당자가 수정할 때의 충돌 처리 (마지막 저장 우선 여부 등)
- 필수 항목 누락 시 저장 방지
- 대량 데이터 일괄 처리(엑셀 업로드 등) 중 일부 실패 시 처리
- 삭제된 참조 데이터(예: 삭제된 프로젝트에 연결된 요구사항)의 표시 여부

## 3. 이력 / 로그
- 변경 이력(누가 언제 무엇을 수정했는지) 기록 여부
- 삭제된 데이터의 복구 가능 여부

## 4. 경계값 / 잘못된 입력
- 페이지네이션 경계 (마지막 페이지, 0건일 때)
- 검색/필터 조건 조합 시 예상과 다른 결과
- 특수문자, 매우 긴 텍스트 입력 시 처리

## 5. 동시성
- 여러 사용자가 동시에 같은 항목 상태를 변경 (예: 승인 처리 동시 클릭)
- 배치/스케줄 작업과 사용자 수동 작업이 겹치는 경우

## 6. 네트워크 / 외부 장애
- 외부 연동 시스템(사내 SSO, 알림 서버 등) 장애 시 화면 동작
- 저장 중 네트워크 끊김 시 데이터 손실 여부
