# 웹/게임 소개 사이트 유형 TC 설계 스킬

제품/게임 소개, 랜딩페이지, 홍보성 웹사이트 프로젝트에서 기획서만으로는
놓치기 쉬운 예외 케이스 체크리스트. 트랜잭션(결제 등)보다는 콘텐츠 노출과
사용자 경험 관점이 중심입니다.

## 1. 반응형 / 크로스 브라우징
- 모바일/태블릿/데스크톱 화면 크기별 레이아웃 깨짐 여부
- 주요 브라우저(Chrome, Safari, Edge) 간 렌더링 차이
- 가로/세로 모드 전환 시 레이아웃 유지

## 2. 폼 / 입력 검증
- 문의하기, 사전예약 등 폼의 필수값 누락 시 처리
- 이메일/전화번호 형식 오류 처리
- 중복 제출(같은 폼 여러 번 빠르게 클릭) 방지

## 3. 콘텐츠 노출 조건
- 팝업/배너 노출 조건 (기간, 언어, 쿠키 동의 여부 등)
- 다국어 지원 시 언어별 콘텐츠 누락 여부
- 이미지/영상 로딩 실패 시 대체 표시(alt, fallback)

## 4. 성능 / 로딩
- 첫 화면 로딩 지연 시 사용자 경험 (로딩 인디케이터 등)
- 대용량 이미지/영상 포함 페이지의 로딩 실패 처리

## 5. SEO / 접근성
- 페이지 타이틀, 메타 디스크립션 누락 여부
- 스크린리더 등 접근성 기본 요소(alt 텍스트, 명도 대비) 여부

## 6. 외부 연동
- SNS 공유 버튼 동작 여부
- 외부 링크(스토어 다운로드 링크 등) 유효성
- 애널리틱스/트래킹 스크립트 정상 동작 여부

## 7. 네트워크 / 예외
- 네트워크 느릴 때 콘텐츠 일부만 로드된 상태의 화면
- 404/에러 페이지 노출 여부
